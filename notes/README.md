# Presora — Notes Vault

This folder is an [Obsidian](https://obsidian.md) vault, versioned in the same
repo as the app so project notes live next to the code they describe.

## Structure

- `decisions/` — short notes on choices worth remembering (why X over Y),
  one file per decision.
- Add topic notes directly in this folder as they come up (roadmap, design
  references, meeting notes, etc.) — no fixed taxonomy, link freely with
  `[[wikilinks]]`.

## Opening this vault

In Obsidian: **Open folder as vault** → select `presora/notes`.

Only this folder is meant to be the vault root — the rest of the repo is
app source code, not notes.
